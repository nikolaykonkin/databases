# Базы данных в облаке

## Задание 1

### Создание кластера

1. Перейдите на главную страницу сервиса Managed Service for PostgreSQL.
2. Создайте кластер PostgreSQL со следующими параметрами:
   - класс хоста: `s2.micro`, диск `network-ssd` любого размера;
   - хосты: два хоста в двух разных зонах доступности, с публичным доступом (публичный IP-адрес);
   - учетная запись для пользователя и базы.
3. Нажмите кнопку «Создать кластер» и дождитесь окончания процесса, статус кластера = `RUNNING`.

### Подключение к мастеру и реплике

1. Скачайте SSL-сертификат и подключитесь к кластеру через `psql`, указав hostname всех узлов и атрибут `target_session_attrs=read-write`.

2. Проверьте, что подключение прошло к master-узлу:

```sql
SELECT CASE WHEN pg_is_in_recovery() THEN 'REPLICA' ELSE 'MASTER' END;
```

3. Посмотрите количество подключенных реплик:

```sql
SELECT count(*) FROM pg_stat_replication;
```

### Проверка работоспособности репликации

1. Создайте таблицу и вставьте одну-две строки:

```sql
CREATE TABLE test_table(text varchar);
INSERT INTO test_table VALUES ('Строка 1');
```

2. Выйдите из `psql` командой `\q`.

3. Подключитесь к узлу-реплике: из команды подключения удалите атрибут `target_session_attrs`, в параметре `host` передайте только имя хоста-реплики.

4. Проверьте, что подключение прошло к узлу-реплике:

```sql
SELECT CASE WHEN pg_is_in_recovery() THEN 'REPLICA' ELSE 'MASTER' END;
```

5. Проверьте состояние репликации:

```sql
SELECT status FROM pg_stat_wal_receiver;
```

6. Выполните запрос к таблице, созданной на предыдущем шаге:

```sql
SELECT * FROM test_table;
```

**Результат:** скриншоты созданной базы данных и вывода команды `SELECT * FROM test_table;` на реплике.
