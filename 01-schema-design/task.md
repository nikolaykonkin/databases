# Задание: проектирование схемы БД

Исходная постановка задачи.

## Легенда

Заказчик передал файл в формате Excel, в котором сформирован отчет. На основе этого отчета нужно выполнить следующие задания.

## Исходные данные

Файл отчета: [source-report.xlsx](docs/source-report.xlsx)

## Задание 1

Описать не менее семи таблиц, из которых состоит база данных. Определить:

- какие данные хранятся в этих таблицах;
- какой тип данных у столбцов в этих таблицах, если данные хранятся в PostgreSQL.

Начертить схему полученной модели данных.

Этапы реализации:

1. Изучить предоставленный файл с данными и сгруппировать данные по смыслу.
2. Разбить исходный файл на несколько таблиц и определить список столбцов в каждой из них.
3. Для каждого столбца подобрать подходящий тип данных PostgreSQL.
4. Для каждой таблицы определить первичный ключ (PRIMARY KEY).
5. Определить типы связей между таблицами.
6. Начертить схему модели данных: таблицы с названиями, столбцы с типами данных, явно выделенные первичные ключи, связи между таблицами.

Результат — схема базы данных.

## Задание 2 (дополнительное)

1. Развернуть СУБД PostgreSQL (хостовая машина, виртуальная машина или контейнер Docker).
2. Описать схему из предыдущего задания скриптом SQL.
3. Создать новую базу данных и выполнить скрипт для создания модели данных.

Результат — SQL-скрипт и диаграмма схемы.
